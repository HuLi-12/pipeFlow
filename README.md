# PipeFlowCheck - 城市排水管网流向合规性检测系统

## 1. 项目定位
PipeFlowCheck 是一个基于有向图遍历的排水管网流向合规性检测系统。系统通过读取 Excel 管网图数据，将节点和通道关系构建为有向图，从指定入口出发遍历所有下游路径，并根据可配置规则判断路径是否最终抵达合法终点。

## 2. 核心原则
- 所有下游路径都必须合法。
- 任意一条路径出现断头、环路、非法通道、非法终点，则该入口判定为错误。
- 输入 Excel 不强制固定死格式，但建议采用节点表、通道表、检测任务表三类数据。
- 规则可配置，可扩展雨水、污水、生活污水、工业废水等入口类型。

## 3. 输入与输出
输入：Excel 管网图数据。
输出：结果 Excel，包含路径、终点、状态、错误原因。

## 4. 推荐技术栈
Java 17 + Spring Boot 3.x + Apache POI/EasyExcel + DFS 全路径遍历 + 可配置规则引擎。
